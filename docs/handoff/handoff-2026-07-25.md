## What this project is

An internal-only local AI appliance deployed on a Proxmox Ubuntu VM with PCIe GPU passthrough (RTX 3060 12 GB). Two trusted users. No public exposure. All documentation is in Australian English.

The repository contains Docker Compose configuration, shell scripts, and documentation. It is **not yet deployed** — this session was an architecture and documentation sprint.

---

## Current stack (fully documented, not yet deployed)

| Service | Image | Role |
|---|---|---|
| Traefik | traefik:v3.5 | Reverse proxy, Let's Encrypt DNS-01/Cloudflare TLS |
| Redis | redis:8-alpine | Authentik session cache / task queue |
| PostgreSQL | pgvector/pgvector:pg17 | Persistent state (openwebui, authentik, mem0 DBs) |
| Authentik | ghcr.io/goauthentik/server:2026.5.4 | OIDC identity provider, groups, MFA |
| Open WebUI | ghcr.io/open-webui/open-webui:v0.10.1 | UI, OIDC-only login, RAG, STT/TTS |
| Ollama | ollama/ollama:0.32.3 | Local LLM inference (GPU) |
| faster-whisper | fedirz/faster-whisper-server:latest-cuda | Speech-to-text (CPU), OpenAI-compatible |
| Kokoro | ghcr.io/remsky/kokoro-fastapi-cpu:latest | Text-to-speech (CPU), OpenAI-compatible |
| Mem0 | mem0ai/mem0:latest | Long-term memory layer (pgvector + Ollama) |

Networks: `ai_proxy` (Traefik-facing), `ai_backend` (internal), `ai_database` (internal)

Documented in `docs/DECISIONS.md` and `AGENTS.md`. Do not silently close — raise with owner:

1. **Traefik Docker socket proxy** — raw socket currently mounted; replace with `tecnativa/docker-socket-proxy` after stack is stable
2. **Traefik dashboard** — disabled (`--api=false`); may be re-enabled behind Authentik forward-auth later
3. **Qdrant** — deferred; Open WebUI uses embedded Chroma, Mem0 uses pgvector; evaluate later
4. **Mem0 user isolation / RBAC** — enforced by: (a) network isolation, (b) pipeline-enforced user_id from OIDC `sub` claim. Authentik Proxy Outpost deferred. Full analysis in `docs/DECISIONS.md`.
5. **Mem0 → Open WebUI pipeline function** — not yet written; required for Mem0 to inject memories into Open WebUI context; must extract `sub` claim from OIDC token as user_id
6. **Image tags** — `FASTER_WHISPER_IMAGE`, `KOKORO_IMAGE`, `MEM0_IMAGE` use `:latest`; must be pinned before production
7. **`MEM0_DB_PASSWORD`** — not yet added to `scripts/generate-secrets.sh`

**Phase 5 — Memory layer (Mem0)**
- Deploy: Mem0

**Phase 6 — Hardening and backups**
- First backup run + Restic snapshot verification
- Systemd timer for nightly backup
- Weekly PBS backup configured
- Pin all image tags to tested releases
- Add Traefik socket proxy (open item)

**Phase 7 — Operational baseline**
